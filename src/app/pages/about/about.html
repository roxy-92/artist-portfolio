About This Project

Artist Showcase is a personal frontend development project built with Angular, TypeScript and SCSS.

It uses my original artwork to demonstrate responsive layouts, dynamic image galleries, category filtering, interactive image viewing and automated asset management.

The project is part of my programming portfolio and is continuously improved as I explore and practise modern frontend development techniques.
